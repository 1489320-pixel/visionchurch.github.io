처음 한 번만 — 열쇠 등록

깃허브 열쇠(토큰)를 한 번 넣어 두면, 다음부터는 이 화면에서 바로 올리실 수 있습니다. 열쇠는 이 컴퓨터의 이 브라우저에만 저장되며 다른 곳으로 전달되지 않습니다.

  1. 깃허브 열쇠 만들기 화면을 엽니다.
  2. Token name에 홈페이지 관리를 적습니다.
  3. Expiration은 No expiration 또는 가장 긴 기간을 고릅니다.
  4. Repository access에서 Only select repositories를 고르고 visionchurch.github.io를 선택합니다.
  5. Repository permissions에서 Contents를 Read and write로 바꿉니다.
  6. 맨 아래 Generate token을 누르고, 나온 글자를 모두 복사해 아래에 붙여 넣습니다.
